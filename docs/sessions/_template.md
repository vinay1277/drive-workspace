# Session: <YYYY-MM-DD-short-slug>

> **Use this template** when starting any new session. Fill in every section.
> If a section doesn't apply, write "N/A" — don't delete it.

## Goal

One sentence. What does success look like at the end of this session?

## Required reading (before writing code)

- `docs/architecture.md` §X.Y
- `docs/decisions/NNNN-*.md` (whichever ADRs constrain this work)
- Any prior session brief whose output this session depends on

Do not read prior session transcripts.

## In scope

Bullet list of files / modules / tasks this session will touch.

## Out of scope

Bullet list of things this session will **not** do, even if tempted.
Anything in this list that turns out to need attention should be added to
`plan.md` for a future session, not done here.

## Definition of done

Concrete, checkable list. Examples:
- [ ] `path/to/file.py` exists and `pytest path/to/tests/` passes.
- [ ] `mypy --strict path/to/module/` is clean.
- [ ] `docs/plan.md` updated to mark task N.M complete.

## Notes / open questions

Things the session-runner should flag back rather than decide unilaterally.
